# Pusula (Rota) tarayıcı

## GitHub Actions ile APK
1. Bu klasörün içeriğini bir GitHub reposuna koy (kök dizin = proje kökü).
2. Actions → workflow çalıştır → **Pusula-APK** artifact.

## Yerel derleme
- JDK 17
- `gradle assembleDebug` (veya Android Studio ile aç)

Eski tek parça `YouTube.yml` workflow artık gerekmez.
